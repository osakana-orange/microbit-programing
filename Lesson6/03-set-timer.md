# じかんをえらぶタイマー 03

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- Aボタンで、はじめの秒数(びょうすう)を `5`、`10`、`15` と変(か)える
- Bボタンを押(お)すと、えらんだ秒数(びょうすう)から数(かぞ)える

## 作(つく)り方(かた)（ブロック）

1. 変数(へんすう) `せってい` と `のこり` を作(つく)る
2. 「最初(さいしょ)だけ」で `せってい` を `5` にする
3. 「ボタンが押(お)されたとき A」で `せってい` を `5` ずつ増(ふ)やす
4. 「もし `せってい` > `15` なら」で、`せってい` を `5` にする
5. 数字(すうじ)を表示(ひょうじ)に `せってい` を入(い)れる
6. 「ボタンが押(お)されたとき B」で `のこり` を `せってい` にする
7. 「`せってい` 回(かい)くりかえす」で、`のこり` を表示(ひょうじ)してから `1000` ミリ秒(びょう)待(ま)つ
8. くりかえしの中(なか)で、`のこり` ひく `1` を `のこり` に入(い)れる。終(お)わったらチェックのマークを表示(ひょうじ)する

## できあがり

- Aボタンを押(お)すたびに、`5`、`10`、`15` 秒(びょう)をえらべる
- Bボタンを押(お)すと、えらんだ時間(じかん)のカウントダウンが始(はじ)まる
