# 10秒(びょう)チャレンジ 04

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- Aボタンでスタートし、もう一度(いちど)Aボタンを押(お)して止(と)める
- `10` 秒(びょう)に近(ちか)いと、にこにこマークを表示(ひょうじ)する

## 作(つく)り方(かた)（ブロック）

1. 変数(へんすう) `じかん` と `はしっている` を作(つく)る
2. 「最初(さいしょ)だけ」で、`じかん` を `0`、`はしっている` を `0` にする
3. 「ボタンが押(お)されたとき A」に「もし `はしっている` = `0` なら」を入(い)れる
4. ならの中(なか)で、`じかん` を `0`、`はしっている` を `1` にする
5. そうでなければの中(なか)で、`はしっている` を `0` にする
6. 「ずっと」の中(なか)に「もし `はしっている` = `1` なら」を入(い)れる
7. ならの中(なか)で、`1000` ミリ秒(びょう)待(ま)ってから `じかん` を `1` ずつ増(ふ)やし、数字(すうじ)を表示(ひょうじ)する
8. Aボタンで止(と)めたとき、「もし `じかん` = `10` なら」で、にこにこマークを表示(ひょうじ)する

## できあがり

- はじめのAボタンで、数(かず)が1秒(びょう)ずつふえる
- もう一度(いちど)Aボタンを押(お)すと、数(かず)が止(と)まる
- ちょうど `10` 秒(びょう)で止(と)めると、にこにこマークが出(で)る
