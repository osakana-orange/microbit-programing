# カウントアップダウン 02

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- Aボタンを押(お)すと、かずが1ふえる
- Bボタンを押(お)すと、かずが1へる
- `9` の次(つぎ)にAボタンを押(お)すと、`0` にもどる
- `0` の次(つぎ)にBボタンを押(お)すと、`9` にもどる

## 作(つく)り方(かた)（ブロック）

1. 「変数(へんすう)」で `かず` を作(つく)る
2. 「最初(さいしょ)だけ」で `かず` を `0` にする
3. 「最初(さいしょ)だけ」で `数字(すうじ)を表示(ひょうじ)` に `かず` を入(い)れる
4. 「ボタンが押(お)されたとき A」で `かず` を `1` ずつ増(ふ)やす
5. その下(した)で「もし `かず` > `9` なら」で `かず` を `0` にする
6. その下(した)で `数字(すうじ)を表示(ひょうじ)` に `かず` を入(い)れる
7. 「ボタンが押(お)されたとき B」で、`かず` ひく `1` を `かず` に入(い)れる
8. その下(した)で「もし `かず` < `0` なら」で `かず` を `9` にする
9. その下(した)で `数字(すうじ)を表示(ひょうじ)` に `かず` を入(い)れる

## できあがり

- はじめに `0` が表示(ひょうじ)される
- Aボタンを押(お)すと、かずがふえる
- `9` の次(つぎ)にAボタンを押(お)すと、`0` にもどる
- Bボタンを押(お)すと、かずがへる
- `0` の次(つぎ)にBボタンを押(お)すと、`9` にもどる
