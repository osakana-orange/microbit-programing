# カウントダウン 02

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- Bボタンを押(お)すと、かずが1へる
- `0` の次(つぎ)にBボタンを押(お)すと、`9` にもどる

## 作(つく)り方(かた)（ブロック）

1. 「変数(へんすう)」で `かず` を作(つく)る
2. 「最初(さいしょ)だけ」で `かず` を `9` にする
3. 「最初(さいしょ)だけ」で `数字(すうじ)を表示(ひょうじ)` に `かず` を入(い)れる
4. 「ボタンが押(お)されたとき B」で `かず` を `1` ずつ減(へ)らす
5. その下(した)で「もし `かず` < `0` なら」で `かず` を `9` にする
6. その下(した)で `数字(すうじ)を表示(ひょうじ)` に `かず` を入(い)れる

## できあがり

- はじめに `9` が表示(ひょうじ)される
- Bボタンを押(お)すたびに、`9, 8, 7...0` とへっていく
- `0` の次(つぎ)にBボタンを押(お)すと、`9` にもどる
