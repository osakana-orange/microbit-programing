# ボタンでメロディ 01

## 使(つか)うもの

- micro:bit V2

## 動(うご)きのれい

- Aボタンを押(お)すと、上(あ)がっていくメロディが鳴(な)る
- Bボタンを押(お)すと、下(さ)がっていくメロディが鳴(な)る

## 作(つく)り方(かた)（ブロック）

1. 「ボタンが押(お)されたとき A」のブロックを出(だ)す
2. 「メロディを鳴(な)らす」のブロックを入(い)れる
3. `ド、レ、ミ、ファ、ソ` の順(じゅん)に音符(おんぷ)をえらぶ
4. 「ボタンが押(お)されたとき B」のブロックを出(だ)す
5. 「メロディを鳴(な)らす」のブロックを入(い)れる
6. `ソ、ファ、ミ、レ、ド` の順(じゅん)に音符(おんぷ)をえらぶ

## できあがり

- Aボタンでは、音(おと)がだんだん高(たか)くなる
- Bボタンでは、音(おと)がだんだん低(ひく)くなる
- ボタンでちがうメロディを楽(たの)しめる

※ 音(おと)を出(だ)すには、micro:bit V2を使(つか)います。
