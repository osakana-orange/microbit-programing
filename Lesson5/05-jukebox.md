# ジュークボックス 01

## 使(つか)うもの

- micro:bit V2

## 動(うご)きのれい

- Aボタンを押(お)すと、次(つぎ)の曲(きょく)をえらぶ
- Bボタンを押(お)すと、テンポが変(か)わる
- A+Bボタンを押(お)すと、えらんだ曲(きょく)が鳴(な)る
- ロゴをタップすると、音(おと)が止(と)まる

## 作(つく)り方(かた)（ブロック）

### 1. へんすうを作(つく)る

1. 「変数(へんすう)」で `きょく` を作(つく)る
2. 「変数(へんすう)」で `テンポ` を作(つく)る
3. 「最初(さいしょ)だけ」で `きょく` を `1` にする
4. 「最初(さいしょ)だけ」で `テンポ` を `100` にする

### 2. 曲(きょく)をえらぶ

1. 「ボタンが押(お)されたとき A」のブロックを出(だ)す
2. `きょく` を `1` ふやす
3. `きょく` が `3` より大(おお)きくなったら、`1` にする
4. `曲(きょく)を表示(ひょうじ)`する

### 3. テンポを変(か)える

1. 「ボタンが押(お)されたとき B」のブロックを出(だ)す
2. `テンポ` を `20` ふやす
3. `テンポ` が `180` より大(おお)きくなったら、`80` にする
4. `テンポ` を表示(ひょうじ)する

### 4. 曲(きょく)を鳴(な)らす

1. 「ボタンが押(お)されたとき A+B」のブロックを出(だ)す
2. 「テンポを設定(せってい)する」に `テンポ` を入(い)れる
3. `きょく` が `1` なら、`ド、レ、ミ、ソ` を鳴(な)らす
4. そうでなく `きょく` が `2` なら、`ソ、ミ、ド、ミ` を鳴(な)らす
5. それ以外(いがい)なら、`ド、ミ、ソ、ド` を鳴(な)らす

### 5. 音(おと)を止(と)める

1. 「ロゴが押(お)されたとき」のブロックを出(だ)す
2. 「すべての音(おと)を止(と)める」のブロックを入(い)れる

## できあがり

- Aボタンで3つの曲(きょく)をえらべる
- Bボタンでテンポを `80`、`100`、`120`、`140`、`160`、`180` と変(か)えられる
- A+Bボタンで曲(きょく)を鳴(な)らせる
- ロゴをタップすると、いつでも音(おと)を止(と)められる

※ 音(おと)を出(だ)すには、micro:bit V2を使(つか)います。
