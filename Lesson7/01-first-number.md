# 1つ目(め)の数(かず) 01

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- Aボタンを押(お)すと、1つ目(め)の数(かず)が `0, 1, 2...9` と変(か)わる
- Bボタンを押(お)すと、えらんだ数(かず)をもう一度(いちど)見(み)せる

## 作(つく)り方(かた)（ブロック）

1. 「変数(へんすう)」で `かず1` を作(つく)る
2. 「最初(さいしょ)だけ」で `かず1` を `0` にする
3. 「ボタンが押(お)されたとき A」で `かず1` を `1` ずつ増(ふ)やす
4. 「もし `かず1` > `9` なら」で、`かず1` を `0` にする
5. 数字(すうじ)を表示(ひょうじ)に `かず1` を入(い)れる
6. 「ボタンが押(お)されたとき B」で、数字(すうじ)を表示(ひょうじ)に `かず1` を入(い)れる

## できあがり

- Aボタンで、1つ目(め)の数(かず)を `0` から `9` までえらべる
- Bボタンで、いまえらんでいる数(かず)をたしかめられる
