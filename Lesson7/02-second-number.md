# 2つ目(め)の数(かず) 02

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- Aボタンで1つ目(め)の数(かず)をえらぶ
- Bボタンで2つ目(め)の数(かず)をえらぶ

## 作(つく)り方(かた)（ブロック）

1. 変数(へんすう) `かず1` と `かず2` を作(つく)る
2. 「最初(さいしょ)だけ」で、`かず1` と `かず2` を `0` にする
3. 「ボタンが押(お)されたとき A」で、`かず1` を `1` ずつ増(ふ)やす
4. `かず1` が `9` より大(おお)きいときは、`0` にする
5. 数字(すうじ)を表示(ひょうじ)に `かず1` を入(い)れる
6. 「ボタンが押(お)されたとき B」で、`かず2` を `1` ずつ増(ふ)やす
7. `かず2` が `9` より大(おお)きいときは、`0` にする
8. 数字(すうじ)を表示(ひょうじ)に `かず2` を入(い)れる

## できあがり

- Aボタンで、1つ目(め)の数(かず)をえらべる
- Bボタンで、2つ目(め)の数(かず)をえらべる
