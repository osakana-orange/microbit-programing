# けいさんきサンプル

Lesson7では、数(かず)をえらんで、たす・ひく・かける・わる計算(けいさん)をするけいさんきを作(つく)ります。

## サンプル

- [01-first-number.md](01-first-number.md): 1つ目(め)の数(かず)をえらぶ
- [02-second-number.md](02-second-number.md): 2つ目(め)の数(かず)をえらぶ
- [03-add.md](03-add.md): たし算(ざん)をする
- [04-subtract.md](04-subtract.md): ひき算(ざん)をする
- [05-multiply.md](05-multiply.md): かけ算(ざん)をする
- [06-divide.md](06-divide.md): わり算(ざん)をする
- [07-choose-operation.md](07-choose-operation.md): 計算(けいさん)のしるしをえらぶ
- [08-show-result.md](08-show-result.md): えらんだ計算(けいさん)の答(こた)えを出(だ)す
- [09-calculator.md](09-calculator.md): 4しゅるいのけいさんができるけいさんき
