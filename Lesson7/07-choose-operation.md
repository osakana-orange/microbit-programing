# けいさんをえらぶ 07

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- Aボタンで、左(ひだり)の数(かず)、計算(けいさん)、右(みぎ)の数(かず)をえらぶ
- Bボタンで決(き)めると、左(ひだり)の数(かず)、計算(けいさん)、右(みぎ)の数(かず)の順番(じゅんばん)に進(すす)む
- 計算(けいさん)をえらぶときは、LEDに `+`、`-`、`×`、`÷` を表示(ひょうじ)する
- 右(みぎ)の数(かず)をBボタンで決(き)めると、答(こた)えが出(で)る

## 作(つく)り方(かた)（ブロック）

1. 変数(へんすう) `かず1`、`かず2`、`えんざん`、`ばめん` を作(つく)る
2. 「最初(さいしょ)だけ」で、4つの変数(へんすう)を `0` にする
3. 「ボタンが押(お)されたとき A」に「もし `ばめん` = `0` なら」を入(い)れる
4. `ばめん` が `0` のときは、`かず1` を `1` ずつ増(ふ)やす。`9` の次(つぎ)は `0` にして、数字(すうじ)を表示(ひょうじ)する
5. そうでなく、`ばめん` が `1` のときは、`えんざん` を `1` ずつ増(ふ)やす。`3` の次(つぎ)は `0` にする
6. `えんざん` が `0` なら文字列(もじれつ)を表示(ひょうじ)に `+`、`1` なら `-`、`2` なら `×`、`3` なら `÷` を入(い)れる
7. それ以外(いがい)では、`かず2` を `1` ずつ増(ふ)やす。`9` の次(つぎ)は `0` にして、数字(すうじ)を表示(ひょうじ)する
8. 「ボタンが押(お)されたとき B」に「もし `ばめん` < `2` なら」を入(い)れ、`ばめん` を `1` ずつ増(ふ)やす
9. そうでなければ、「もし `えんざん` = `0` なら」で `かず1 + かず2` を表示(ひょうじ)する
10. `えんざん` が `1` なら `かず1 - かず2`、`2` なら `かず1 * かず2` を表示(ひょうじ)する
11. `えんざん` が `3` なら、`かず2` が `0` のときは×、ちがうときは `かず1 / かず2` を表示(ひょうじ)する
12. 答(こた)えを表示(ひょうじ)した後(あと)に、`ばめん` を `0` にする

## できあがり

- Aボタンで、左(ひだり)の数(かず)、計算(けいさん)、右(みぎ)の数(かず)をえらべる
- 右(みぎ)の数(かず)をBボタンで決(き)めると、答(こた)えが表示(ひょうじ)される
- 答(こた)えを出(だ)した後(あと)は、また左(ひだり)の数(かず)をえらぶところにもどる
- 計算(けいさん)をえらぶときは、LEDに `+`、`-`、`×`、`÷` が順番(じゅんばん)に出(で)る
