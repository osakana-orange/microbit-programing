# ひき算(ざん) 04

## 使(つか)うもの

- micro:bit V2

## 動(うご)きのれい

- Aボタンで1つ目(め)の数(かず)、Bボタンで2つ目(め)の数(かず)をえらぶ
- ロゴをタッチすると、1つ目(め)の数(かず)から2つ目(め)の数(かず)をひいた答(こた)えが出(で)る

## 作(つく)り方(かた)（ブロック）

1. 変数(へんすう) `かず1` と `かず2` を作(つく)る
2. 「最初(さいしょ)だけ」で、`かず1` と `かず2` を `0` にする
3. 「ボタンが押(お)されたとき A」で、`かず1` を `1` ずつ増(ふ)やす。`9` の次(つぎ)は `0` にして表示(ひょうじ)する
4. 「ボタンが押(お)されたとき B」で、`かず2` を `1` ずつ増(ふ)やす。`9` の次(つぎ)は `0` にして表示(ひょうじ)する
5. 「ロゴが押(お)されたとき」で、数字(すうじ)を表示(ひょうじ)に `かず1 - かず2` を入(い)れる

## できあがり

- AボタンとBボタンで、ひきたい2つの数(かず)をえらべる
- ロゴをタッチすると、ひき算(ざん)の答(こた)えが表示(ひょうじ)される
- 小(ちい)さい数(かず)から大(おお)きい数(かず)をひくと、`-` のついた数(かず)が出(で)る

※ ロゴのタッチを使(つか)うには、micro:bit V2が必要(ひつよう)です。
