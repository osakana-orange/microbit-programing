# たし算(ざん) 03

## 使(つか)うもの

- micro:bit V2

## 動(うご)きのれい

- Aボタンで1つ目(め)の数(かず)、Bボタンで2つ目(め)の数(かず)をえらぶ
- ロゴをタッチすると、2つの数(かず)をたした答(こた)えが出(で)る

## 作(つく)り方(かた)（ブロック）

1. 変数(へんすう) `かず1` と `かず2` を作(つく)る
2. 「最初(さいしょ)だけ」で、`かず1` と `かず2` を `0` にする
3. 「ボタンが押(お)されたとき A」で、`かず1` を `1` ずつ増(ふ)やす
4. 「もし `かず1` > `9` なら」で、`かず1` を `0` にする。その下(した)で `かず1` を表示(ひょうじ)する
5. 「ボタンが押(お)されたとき B」で、`かず2` を `1` ずつ増(ふ)やす
6. 「もし `かず2` > `9` なら」で、`かず2` を `0` にする。その下(した)で `かず2` を表示(ひょうじ)する
7. 「ロゴが押(お)されたとき」で、数字(すうじ)を表示(ひょうじ)に `かず1 + かず2` を入(い)れる

## できあがり

- AボタンとBボタンで、たしたい2つの数(かず)をえらべる
- ロゴをタッチすると、たし算(ざん)の答(こた)えが表示(ひょうじ)される

※ ロゴのタッチを使(つか)うには、micro:bit V2が必要(ひつよう)です。
