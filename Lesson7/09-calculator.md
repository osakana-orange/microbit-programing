# けいさんき 09

## 使(つか)うもの

- micro:bit V2

## 動(うご)きのれい

- Aボタンで、左(ひだり)の数(かず)、計算(けいさん)、右(みぎ)の数(かず)をえらぶ
- Bボタンで決(き)めると、左(ひだり)の数(かず)、計算(けいさん)、右(みぎ)の数(かず)の順番(じゅんばん)に進(すす)む
- 右(みぎ)の数(かず)をBボタンで決(き)めると答(こた)えが出(で)、ロゴをタッチすると前(まえ)の答(こた)えが見(み)られる

## 作(つく)り方(かた)（ブロック）

### 1. へんすうを作(つく)る

1. `かず1`、`かず2`、`えんざん`、`ばめん`、`まえのこたえ` の5つの変数(へんすう)を作(つく)る
2. 「最初(さいしょ)だけ」で、5つの変数(へんすう)を `0` にする

### 2. Aボタンでえらぶ

1. 「ボタンが押(お)されたとき A」に「もし `ばめん` = `0` なら」を入(い)れる
2. `ばめん` が `0` のときは、`かず1` を `1` ずつ増(ふ)やし、`9` の次(つぎ)は `0` にして数字(すうじ)を表示(ひょうじ)する
3. そうでなく、`ばめん` が `1` のときは、`えんざん` を `1` ずつ増(ふ)やす。`4` の次(つぎ)は `0` にする
4. `えんざん` が `0` なら文字列(もじれつ)を表示(ひょうじ)に `+`、`1` なら `-`、`2` なら `×`、`3` なら `÷`、`4` なら `C` を入(い)れる
5. それ以外(いがい)では、`かず2` を `1` ずつ増(ふ)やし、`9` の次(つぎ)は `0` にして数字(すうじ)を表示(ひょうじ)する

### 3. Bボタンでつぎへ進(すす)む

1. 「ボタンが押(お)されたとき B」に「もし `ばめん` < `2` なら」を入(い)れる
2. `ばめん` が `0` または `1` のときは、`ばめん` を `1` ずつ増(ふ)やす
3. `ばめん` が `2` で `えんざん` が `4` なら、`かず1` と `かず2` を `0` にして、文字列(もじれつ)を表示(ひょうじ)に `C` を入(い)れる
4. `ばめん` が `2` で `えんざん` が `0` なら、`まえのこたえ` を `かず1 + かず2` にして表示(ひょうじ)する
5. `えんざん` が `1` なら `まえのこたえ` を `かず1 - かず2`、`2` なら `かず1 * かず2` にして表示(ひょうじ)する
6. `えんざん` が `3` なら、`かず2` が `0` のときは×、ちがうときは `まえのこたえ` を `かず1 / かず2` にして表示(ひょうじ)する
7. 答(こた)えか `C` を表示(ひょうじ)した後(あと)に、`ばめん` を `0` にする

### 4. ロゴで前(まえ)の答(こた)えを見(み)る

1. 「ロゴが押(お)されたとき」のブロックを出(だ)す
2. 数字(すうじ)を表示(ひょうじ)に `まえのこたえ` を入(い)れる

## できあがり

- AボタンとBボタンで、2つの数(かず)と `+`、`-`、`×`、`÷`、`C` をえらべる
- 右(みぎ)の数(かず)をBボタンで決(き)めると、4しゅるいの計算(けいさん)の答(こた)えを表示(ひょうじ)できる
- `C` を決(き)めると、いま入(い)れた2つの数(かず)が `0` にもどる
- ロゴをタッチすると、前(まえ)に計算(けいさん)した答(こた)えが表示(ひょうじ)される
- `0` でわるときは、×が表示(ひょうじ)される

※ ロゴのタッチを使(つか)うには、micro:bit V2が必要(ひつよう)です。
