# テトリス

## 概要
1. ランダムで ・、・・（横）、・・（縦）の3種類が上から下の落ちてくる
2. Aボタンで、落ちてくる点を左に移動、Bボタンで落ちてくる点を右に移動
3. AとBの同時押しで、・・（横）と・・（縦）を入替
4. ・が下に移動したときに、すでに下に・存在するときは、積み上げる。
5. ・が 5x5の一番上まで到達したらGameOver
6. GameOverでAとBの同時押しで、リセットして最初から開始
7. 一番下に落下したときに、横一列に点が並ぶと、ラインを消して、1行上のラインを下に入れ替える。

## 学習コンテンツ
1. 点を(3, 0): (よこ, たて)のLEDに表示する
2. AとBで点のLEDを左右に移動する
3. 500msで点のLED下に移動する
4. たてが4になったら、よこを2、たてを0に戻す
5. 点を積み上げる
6. 1番上まで積み上げたらGameOver
7. リセット
8. 横一列に点が並んだら、ラインを消す。
9. 横一列に点が並んだら、ラインを消して、上のラインを下に下げる
10. 点のバリエーションを増やす。`・・（横）`と`・・(縦)`
11. ・・の場合、AとBの同時押しで、横と縦を入れ替え
12. 2ライン同時消しに対応する
13. ラインを消したらスコアに+1とする。2ライン同時消しの場合は +5とする
14. GameOver時にスコアを表示する
