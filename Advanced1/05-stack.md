# テトリス 05

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- 点(てん)が `500` ミリ秒(びょう)ごとに下(した)へ動(うご)く
- 下(した)のLEDが点(つ)いていなければ、点(てん)が下(した)へ動(うご)く
- 下(した)のLEDが点(つ)いていると、点(てん)が画面(がめん)の上(うえ)に戻(もど)る
- 一番(いちばん)下(した)まで行(い)った点(てん)は、画面(がめん)に残(のこ)る

## 作(つく)り方(かた)（ブロック）

1. `よこ` の変数(へんすう)を作(つく)る
2. `たて` の変数(へんすう)を作(つく)る
3. 「最初(さいしょ)だけ」の中(なか)に、`よこ` を `2` にするブロックを入(い)れる
4. 「最初(さいしょ)だけ」の中(なか)に、`たて` を `0` にするブロックを入(い)れる
5. 「ずっと」の中(なか)に「LED > 点灯(てんとう)」を入(い)れる
6. 「LED > 点灯(てんとう)」の `x` に、変数(へんすう) `よこ` を入(い)れる
7. 「LED > 点灯(てんとう)」の `y` に、変数(へんすう) `たて` を入(い)れる
8. 「一時停止(いちじていし)」を入(い)れる
9. 待(ま)ち時間(じかん)を `500` ミリ秒(びょう)にする
10. 「LED > 点灯(てんとう)している」を使(つか)う
11. `x` に変数(へんすう) `よこ` を入(い)れる
12. `y` に、変数(へんすう) `たて + 1` を入(い)れる
13. 「もし」を入(い)れる
14. 条件(じょうけん)に `たて < 4` を入(い)れる
15. 条件(じょうけん)の中(なか)に、もう1つ「もし」を入(い)れる
16. 内側(うちがわ)の条件(じょうけん)に「LED > 点灯(てんとう)している」が「でない」を入(い)れる
17. 内側(うちがわ)の条件(じょうけん)の中(なか)に「LED > 消灯(しょうとう)」を入(い)れる
18. 「LED > 消灯(しょうとう)」の `x` に、変数(へんすう) `よこ` を入(い)れる
19. 「LED > 消灯(しょうとう)」の `y` に、変数(へんすう) `たて` を入(い)れる
20. 内側(うちがわ)の条件(じょうけん)の中(なか)に「変数(へんすう) `たて` を `0` にする」を入(い)れる
21. 「変数(へんすう) `たて` を `0` にする」の右(みぎ)の `0` に、`0 + 0` の計算(けいさん)ブロックを入(い)れる
22. 計算(けいさん)ブロックの左(ひだり)に、変数(へんすう) `たて` を入(い)れる
23. 計算(けいさん)ブロックの右(みぎ)に、`1` を入(い)れる
24. 「でなければ」の中(なか)に、`よこ` を `2` にするブロックを入(い)れる
25. 「でなければ」の中(なか)に、`たて` を `0` にするブロックを入(い)れる
26. 外側(そとがわ)の「もし」の「でなければ」を入(い)れる
27. 「でなければ」の中(なか)に、`よこ` を `2` にするブロックを入(い)れる
28. 「でなければ」の中(なか)に、`たて` を `0` にするブロックを入(い)れる

## できあがり

- 点(てん)が下(した)へ動(うご)き、下(した)のLEDが点(つ)いていると上(うえ)に戻(もど)る
- 「LED > 消灯(しょうとう)」を使(つか)うので、動(うご)く前(まえ)の点(てん)が残(のこ)らない
- 点(てん)が一番(いちばん)下(した)に着(つ)くと、そこに残(のこ)る
