# テトリス 03

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- 点(てん)が `500` ミリ秒(びょう)ごとに、下(した)へ1つ動(うご)く
- 点(てん)が画面(がめん)の一番(いちばん)下(した)まで行(い)くと、そこで止(と)まる
- AボタンとBボタンで、落(お)ちている点(てん)を左右(さゆう)に動(うご)かせる

## 作(つく)り方(かた)（ブロック）

1. `よこ` の変数(へんすう)を作(つく)る
2. `たて` の変数(へんすう)を作(つく)る
3. 「最初(さいしょ)だけ」の中(なか)に、`よこ` を `2` にするブロックを入(い)れる
4. 「最初(さいしょ)だけ」の中(なか)に、`たて` を `0` にするブロックを入(い)れる
5. 「ボタンが押(お)されたとき A」を出(だ)す
6. 「もし」を「ボタンが押(お)されたとき A」の中(なか)に入(い)れる
7. 条件(じょうけん)に `よこ > 0` を入(い)れる
8. 条件(じょうけん)の中(なか)に「LED > 消灯(しょうとう)」を入(い)れる
9. 「LED > 消灯(しょうとう)」の `x` に、変数(へんすう) `よこ` を入(い)れる
10. 「LED > 消灯(しょうとう)」の `y` に、変数(へんすう) `たて` を入(い)れる
11. 条件(じょうけん)の中(なか)に「変数(へんすう) `よこ` を `0` にする」を入(い)れる
12. 「変数(へんすう) `よこ` を `0` にする」の右(みぎ)の `0` に、`0 - 0` の計算(けいさん)ブロックを入(い)れる
13. 計算(けいさん)ブロックの左(ひだり)の `0` に、変数(へんすう) `よこ` を入(い)れる
14. 計算(けいさん)ブロックの右(みぎ)の `0` に、`1` を入(い)れる
15. 「ボタンが押(お)されたとき B」を出(だ)す
16. 「もし」を「ボタンが押(お)されたとき B」の中(なか)に入(い)れる
17. 条件(じょうけん)に `よこ < 4` を入(い)れる
18. 条件(じょうけん)の中(なか)に「LED > 消灯(しょうとう)」を入(い)れる
19. 「LED > 消灯(しょうとう)」の `x` に、変数(へんすう) `よこ` を入(い)れる
20. 「LED > 消灯(しょうとう)」の `y` に、変数(へんすう) `たて` を入(い)れる
21. 条件(じょうけん)の中(なか)に「変数(へんすう) `よこ` を `0` にする」を入(い)れる
22. 「変数(へんすう) `よこ` を `0` にする」の右(みぎ)の `0` に、`0 + 0` の計算(けいさん)ブロックを入(い)れる
23. 計算(けいさん)ブロックの左(ひだり)の `0` に、変数(へんすう) `よこ` を入(い)れる
24. 計算(けいさん)ブロックの右(みぎ)の `0` に、`1` を入(い)れる
25. `よこ` と `たて` の場所(ばしょ)に「LED > 点灯(てんとう)」を使(つか)う
26. 「一時停止(いちじていし) `500` ミリ秒(びょう)」を入(い)れる
27. 「もし」を入(い)れる
28. 条件(じょうけん)に `たて < 4` を入(い)れる
29. 条件(じょうけん)の中(なか)に「LED > 消灯(しょうとう)」を入(い)れる
30. 「LED > 消灯(しょうとう)」の `x` に、変数(へんすう) `よこ` を入(い)れる
31. 「LED > 消灯(しょうとう)」の `y` に、変数(へんすう) `たて` を入(い)れる
32. 条件(じょうけん)の中(なか)に「変数(へんすう) `たて` を `0` にする」を入(い)れる
33. 「変数(へんすう) `たて` を `0` にする」の右(みぎ)の `0` に、`0 + 0` の計算(けいさん)ブロックを入(い)れる
34. 計算(けいさん)ブロックの左(ひだり)の `0` に、変数(へんすう) `たて` を入(い)れる
35. 計算(けいさん)ブロックの右(みぎ)の `0` に、`1` を入(い)れる
36. 「でなければ」を入(い)れる
37. 「でなければ」の中(なか)に `たて` を `4` にするブロックを入(い)れる

## できあがり

- 点(てん)が上(うえ)から下(した)へ落(お)ちる
- 一番(いちばん)下(した)に着(つ)くと、それ以上(いじょう)落(お)ちない
