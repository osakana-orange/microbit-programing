# サイコロ 02

## 使(つか)うもの

- micro:bit

## 動(うご)きのれい

- micro:bitをゆさぶると、ハートが大(おお)きくなったり小(ちい)さくなったりする
- micro:bitをゆさぶるのをやめると、1から6までの数字(すうじ)が1つ表示(ひょうじ)される

## 作(つく)り方(かた)（ブロック）

1. 「ゆさぶられたとき」のブロックを出(だ)す
2. 「アイコンを表示(ひょうじ)」でハートを表示(ひょうじ)する
3. 「一時停止(いちじていし)」を入(い)れ、`200` ミリびょうにする
4. 「アイコンを表示(ひょうじ)」で小(ちい)さいハートを表示(ひょうじ)する
5. 「一時停止(いちじていし)」を入(い)れ、`200` ミリびょうにする
6. 「1から6までの乱数(らんすう)」を作(つく)る
7. 「数字(すうじ)を表示(ひょうじ)」に、できた数字(すうじ)を入(い)れる

## できあがり

- micro:bitをゆさぶると、ハートがドキドキする
- ゆさぶるのをやめると、`1, 2, 3, 4, 5, 6` のどれかが表示(ひょうじ)される
