# すうじあてゲーム 03

## 使(つか)うもの

- micro:bit

## ゲームのルール

- micro:bitをゆさぶると、`0` から `9` までの数字(すうじ)を1つえらぶ
- えらんだ数字(すうじ)は、すぐには見(み)えない
- Aボタンを押(お)すと、答(こた)えの数字(すうじ)をえらべる
- ロゴをタップすると、かくれていた数字(すうじ)が見(み)える
- Bボタンを押(お)すと、えらんだ数字(すうじ)が大(おお)きいか小(ちい)さいか、たしかめる

## 動(うご)きのれい

- ゆさぶると、ハートがドキドキして、数字(すうじ)が決(き)まる
- ロゴをタップするまで、決(き)まった数字(すうじ)は見(み)えない
- Aボタンで、答(こた)えの数字(すうじ)をえらぶ
- ロゴをタップすると、決(き)まった数字(すうじ)が表示(ひょうじ)される
- Bボタンを押(お)すと、答(こた)えと同(おな)じなら「○」、大(おお)きければ「＞」、小(ちい)さければ「＜」が表示(ひょうじ)される

## 作(つく)り方(かた)（ブロック）

### 1. へんすうを作(つく)る

1. 「変数(へんすう)」で `あたりのかず` を作(つく)る
2. 「変数(へんすう)」で `えらんだかず` を作(つく)る
3. 「最初(さいしょ)だけ」で `えらんだかず` を `0` にする

### 2. ゆさぶったとき

1. 「ゆさぶられたとき」のブロックを出(だ)す
2. `あたりのかず` を、`0` から `9` までの乱数(らんすう)にする
3. 「アイコンを表示(ひょうじ)」でハートを表示(ひょうじ)する
4. 「一時停止(いちじていし)」を入(い)れ、`200` ミリびょうにする
5. 「アイコンを表示(ひょうじ)」で小(ちい)さいハートを表示(ひょうじ)する
6. 「一時停止(いちじていし)」を入(い)れ、`200` ミリびょうにする
7. 「画面(がめん)を消(け)す」で、数字(すうじ)を見(み)えなくする

### 3. Aボタンを押(お)したとき

1. 「ボタンが押(お)されたとき A」のブロックを出(だ)す
2. `えらんだかず` を `1` ずつ増(ふ)やす
3. もし `えらんだかず` が `9` より大(おお)きくなったら、`0` にする
4. `えらんだかず` を数字(すうじ)で表示(ひょうじ)する

### 4. ロゴをタップしたとき

1. 「ロゴが押(お)されたとき」のブロックを出(だ)す
2. 「数字(すうじ)を表示(ひょうじ)」に `あたりのかず` を入(い)れる

### 5. Bボタンを押(お)したとき

1. 「ボタンが押(お)されたとき B」のブロックを出(だ)す
2. もし `えらんだかず` と `あたりのかず` が同(おな)じなら、「○」を表示(ひょうじ)する
3. そうでなく、`えらんだかず` が `あたりのかず` より大(おお)きければ、「＞」を表示(ひょうじ)する
4. それ以外(いがい)なら、「＜」を表示(ひょうじ)する

## できあがり

- ゆさぶると、かくれた数字(すうじ)が決(き)まる
- Aボタンで `0` から `9` の数字(すうじ)をえらべる
- ロゴをタップすると、決(き)まった数字(すうじ)が見(み)える
- Bボタンで答(こた)えをたしかめられる
