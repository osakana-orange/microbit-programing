# すうじあてゲーム 01

## 使(つか)うもの

- micro:bit

## ゲームのルール

- micro:bitをゆさぶると、`0` から `9` までの数字(すうじ)を1つえらぶ
- Aボタンを押(お)すと、えらぶ数字(すうじ)が `0, 1, 2...` とかわる
- `9` の次(つぎ)にAボタンを押(お)すと、`0` にもどる
- Bボタンを押(お)すと、えらんだ数字(すうじ)があたっているかたしかめる

## 動(うご)きのれい

- ゆさぶると、ハートがドキドキして、かくれた数字(すうじ)が決(き)まる
- Aボタンで、答(こた)えの数字(すうじ)をえらぶ
- Bボタンを押(お)して、答(こた)えがあっていたら「○」を表示(ひょうじ)する
- 答(こた)えがちがっていたら「×」を表示(ひょうじ)する

## 作(つく)り方(かた)（ブロック）

### 1. へんすうを作(つく)る

1. 「変数(へんすう)」で `あたりのかず` を作(つく)る
2. 「変数(へんすう)」で `えらんだかず` を作(つく)る
3. 「最初(さいしょ)だけ」で `えらんだかず` を `0` にする

### 2. ゆさぶったとき

1. 「ゆさぶられたとき」のブロックを出(だ)す
2. `あたりのかず` を、`0` から `9` までの乱数(らんすう)にする
3. 「アイコンを表示(ひょうじ)」でハートを表示(ひょうじ)する
4. 「一時停止(いちじていし)」を入(い)れ、`200` ミリびょうにする
5. 「アイコンを表示(ひょうじ)」で小(ちい)さいハートを表示(ひょうじ)する
6. 「一時停止(いちじていし)」を入(い)れ、`200` ミリびょうにする

### 3. Aボタンを押(お)したとき

1. 「ボタンが押(お)されたとき A」のブロックを出(だ)す
2. `えらんだかず` を `1` ずつ増(ふ)やす
3. もし `えらんだかず` が `9` より大(おお)きくなったら、`0` にする
4. `えらんだかず` を数字(すうじ)で表示(ひょうじ)する

### 4. Bボタンを押(お)したとき

1. 「ボタンが押(お)されたとき B」のブロックを出(だ)す
2. もし `えらんだかず` と `あたりのかず` が同(おな)じなら、○を表示(ひょうじ)する
3. ちがうときは、×を表示(ひょうじ)する

## できあがり

- ゆさぶると、かくれた数字(すうじ)が決(き)まる
- Aボタンで `0` から `9` の数字(すうじ)をえらべる
- Bボタンで答(こた)えをたしかめられる
- 答(こた)えがあっていると○、ちがうと×が表示(ひょうじ)される
