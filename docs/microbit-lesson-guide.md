# micro:bit教材(きょうざい) 作成(さくせい)ガイド

## 目的(もくてき)

このガイドは、micro:bitの教材(きょうざい)を、生成AIで何度(なんど)も作(つく)れるようにするためのものです。
対象(たいしょう)は、小学(しょうがく)1年生(ねんせい)です。

## 教材(きょうざい)の基本(きほん)の形(かた)

1. タイトル
2. `使(つか)うもの`
3. `動(うご)きのれい`
4. `作(つく)り方(かた)（ブロック）`
5. `できあがり`
6. 必要(ひつよう)なら注意(ちゅうい)

テンプレートは `templates/microbit-lesson.md` を使(つか)います。

## 文章(ぶんしょう)のルール

- ひらがなを基本(きほん)にする
- 漢字(かんじ)には、すぐ後(うし)ろに `(よみがな)` を付(つ)ける
- 一文(いちぶん)を短(みじか)くする
- 「何(なに)をすると、何(なに)が起(お)きるか」で書(か)く
- 1つの教材(きょうざい)は、前(まえ)の教材(きょうざい)を使(つか)わず、毎回(まいかい)最初(さいしょ)から作(つく)れるように書(か)く
- MakeCodeのブロック名(めい)は、実際(じっさい)の名前(なまえ)に近(ちか)く書(か)く
- 場所(ばしょ)を表(あらわ)す変数名(へんすうめい)は、`よこ` や `たて` のように分(わ)かりやすくする
- 変数(へんすう)を増(ふ)やしたり減(へ)らしたりするときは、変数(へんすう)に `変数 + 数(かず)` や `変数 - 数(かず)` を入(い)れると書(か)く
- 「変数(へんすう)を `1` ずつ増(ふ)やす」「変数(へんすう)を `1` ずつ減(へ)らす」というブロック名(めい)は書(か)かない
- 変数(へんすう)を作(つく)るときは、変数名(へんすうめい)と、はじめに入(い)れる数(かず)や入(い)れる値(あたい)を必(かなら)ず書(か)く
- 計算(けいさん)は、変数(へんすう)を `0` にするブロック、計算(けいさん)ブロック、左(ひだり)の数(かず)、右(みぎ)の数(かず)の順番(じゅんばん)に書(か)く
- 数字(すうじ)、英字(えいじ)、記号(きごう)はバッククォートで囲(かこ)む
- `実行例` と `完成イメージ` は使(つか)わず、`動(うご)きのれい` と `できあがり` にそろえる
- `最初(さいしょ)だけ` と `ずっと` は最初(さいしょ)から置(お)かれているため、「出(だ)す」と書(か)かない
- はじめの数(かず)は「最初(さいしょ)だけ」の中(なか)に入(い)れると書(か)く
- 使(つか)わない `最初(さいしょ)だけ` や `ずっと` は、最初(さいしょ)に消(け)すと書(か)く

## センサー教材(きょうざい)のルール

- 1つの教材(きょうざい)では、基本(きほん)的(てき)に1つのセンサーだけを使(つか)う
- センサー同士(どうし)を組(く)み合(あ)わせない
- センサー以外(いがい)の表示(ひょうじ)・音(おと)・変数(へんすう)は使(つか)ってよい
- micro:bit V2だけの機能(きのう)は、`使(つか)うもの` と注意(ちゅうい)に `micro:bit V2` と書(か)く
- 温度(おんど)は本体(ほんたい)の温度(おんど)であり、部屋(へや)の温度(おんど)とは違(ちが)うことがある

## レベル別(べつ)の作(つく)り方(かた)

### Lesson1: 変数(へんすう)と数(かず)

- A/Bボタンで数(かず)を増(ふ)やす・減(へ)らす
- `もし` で0〜9の範囲(はんい)に戻(もど)す
- 最初(さいしょ)の値(あたい)を明確(めいかく)にする

### Lesson2: 乱数(らんすう)と表示(ひょうじ)

- ゆさぶりで乱数(らんすう)を作(つく)る
- ハートの大(おお)きさや数字(すうじ)で動(うご)きを見(み)せる
- 必要(ひつよう)なら、一時停止(いちじていし)を入(い)れる

### Lesson3: ゲーム

- `あたりのかず` と `えらんだかず` のように、役割(やくわり)が分(わ)かる変数名(へんすうめい)にする
- 正解(せいかい)・大(おお)きい・小(ちい)さいを条件(じょうけん)で分(わ)ける
- ロゴタップなどの入力(にゅうりょく)を使(つか)うときは、対応(たいおう)するV2条件(じょうけん)を確認(かくにん)する

### Lesson4: センサーと出力(しゅつりょく)

- センサーの値(あたい)を数字(すうじ)、文字(もじ)、矢印(やじるし)、音(おと)に変(か)える
- 例(れい): 明(あか)るさを0〜9、明(あか)るさを音(おと)の高(たか)さに変(か)える
- 1教材(きょうざい)1センサーを守(まも)る

## 生成AIへの依頼(いらい)の型(かた)

次(つぎ)の情報(じょうほう)を渡(わた)します。

- レッスン番号(ばんごう)
- ファイル名(めい)
- 使(つか)うセンサー、ボタン、出力(しゅつりょく)
- 期待(きたい)する動(うご)き
- V2限定(げんてい)かどうか
- 既存(きそん)教材(きょうざい)との違(ちが)い

依頼(いらい)の例(れい):

> Lesson4の次(つぎ)の教材(きょうざい)を作(つく)ってください。明(あか)るさセンサーだけを使(つか)い、明(あか)るさを音(おと)の高(たか)さに変(か)えます。小学(しょうがく)1年生(ねんせい)向(む)け、漢字(かんじ)によみがなを付(つ)け、`動(うご)きのれい`、`作(つく)り方(かた)（ブロック）`、`できあがり` の順(じゅん)にしてください。

## 完成前(かんせいまえ)チェック

- [ ] ファイル名(めい)が連番(れんばん)になっている
- [ ] 見出(みだ)しがテンプレートと同(おな)じ順番(じゅんばん)になっている
- [ ] 漢字(かんじ)によみがながある
- [ ] 空(から)の手順(てじゅん)や `xxx` がない
- [ ] 動(うご)きの説明(せつめい)とブロック手順(てじゅん)が一致(いっち)している
- [ ] 前(まえ)の教材(きょうざい)を使(つか)う手順(てじゅん)や「残(のこ)す」という書(か)き方(かた)がない
- [ ] 変数(へんすう)の増減(ぞうげん)を、計算(けいさん)した数(かず)を変数(へんすう)に入(い)れる手順(てじゅん)で書(か)いている
- [ ] `最初(さいしょ)だけ` と `ずっと` を出(だ)す手順(てじゅん)を書(か)いていない
- [ ] 使(つか)わない `最初(さいしょ)だけ` や `ずっと` を最初(さいしょ)に消(け)す手順(てじゅん)がある
- [ ] V2限定(げんてい)の機能(きのう)を明記(めいき)している
- [ ] センサーの組(く)み合(あ)わせをしていない
- [ ] 生成AIが作(つく)った内容(ないよう)を、MakeCodeのブロック名(めい)と照(て)らし合(あ)わせた
